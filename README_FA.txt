پروژه SINA AI – نسخه توسعه‌یافته ۲
====================================

قابلیت‌های موجود در کد این نسخه:
- گفت‌وگوی فارسی از طریق API سازگار با OpenAI Chat Completions
- تشخیص گفتار با سرویس گفتار اندروید و پاسخ صوتی TTS
- بیدارباش آزمایشی با عبارت‌های «سینا»، «ممد قلی» و «محمد قلی» از طریق Foreground Service
- حالت آفلاین پایه برای فرمان‌ها و پاسخ‌های ساده و ثابت
- درخواست تولید تصویر از مسیر استاندارد /images/generations
- درخواست تولید ویدئو با endpoint و مدل قابل تنظیم و نمایش ویدئوی برگشتی در صورت ارائه لینک مستقیم
- فرمان‌های محلی: ساعت، تاریخ، تنظیمات، وای‌فای، بلوتوث، شماره‌گیر، پیامک و دوربین

راه‌اندازی بیدارباش:
1) برنامه را باز کن و مجوز میکروفون را بده.
2) دکمه «فعال‌سازی بیدارباش» را بزن؛ سرویس با اعلان دائمی اجرا می‌شود.
3) عبارت «سینا» یا «ممد قلی» را بگو. برای خاموش‌کردن، دکمه توقف را بزن.
محدودیت مهم: این پیاده‌سازی از SpeechRecognizer اندروید استفاده می‌کند، نه موتور اختصاصی wake-word. تشخیص مداوم ممکن است در بعضی گوشی‌ها/نسخه‌ها متوقف شود یا به سرویس تشخیص گفتار دستگاه وابسته باشد. حالت آفلاین تشخیص فقط وقتی کار می‌کند که سرویس تشخیص گفتار آفلاین فارسی روی گوشی نصب و پشتیبانی شود. محدودیت‌های باتری و سازنده گوشی نیز ممکن است اجرای پس‌زمینه را محدود کنند.

حالت آفلاین:
- از تنظیمات، «حالت آفلاین پایه» را روشن کن.
- این حالت بدون اینترنت، چند فرمان و پاسخ ساده را اجرا می‌کند.
- این نسخه هنوز مدل زبانی مولد کامل (LLM) را داخل گوشی اجرا نمی‌کند. برای مکالمه آزاد آفلاین باید فایل مدل سازگار با سخت‌افزار گوشی و موتور اجرای محلی جداگانه اضافه شود؛ پاسخ‌های این حالت را با هوش مصنوعی کامل اشتباه نگیر.

تولید ویدئو:
- از تنظیمات، کلید API، نشانی کامل endpoint و نام مدل سرویس ویدئو را وارد کن.
- دکمه «ویدئو» را بزن و توضیح ویدئو را در کادر بنویس.
- چون سرویس‌های تولید ویدئو API و قالب پاسخ یکسانی ندارند، این کد درخواست JSON شامل model و prompt می‌فرستد و چند قالب رایج لینک خروجی را بررسی می‌کند. ممکن است برای سرویس انتخابی نیاز به تطبیق کد باشد؛ بعضی سرویس‌ها ابتدا job id می‌دهند و به polling نیاز دارند.

امنیت و حریم خصوصی:
- کلید API در SharedPreferences ذخیره می‌شود و برای انتشار عمومی باید به Android Keystore منتقل شود.
- سرویس بیدارباش در زمان فعال بودن میکروفون را در پس‌زمینه استفاده می‌کند و اعلان دائمی نمایش می‌دهد. فقط با رضایت کاربر فعالش کن و پس از استفاده خاموشش کن.

ساخت APK:
- پوشه SINA_AI_Android_Project را در Android Studio باز کن.
- Gradle Sync را اجرا کن و سپس از Build > Build APK(s) خروجی بگیر.
- این پروژه در محیط حاضر کامپایل و روی گوشی آزمایش نشده است؛ قبل از نصب، در Android Studio بساز و خطاهای احتمالی را بررسی کن.
